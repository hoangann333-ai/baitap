## 1. Tạo CSDL bằng giao diện MySQL Workbench

- Nhấp chuột phải trong SCHEMAS → Create Schema.
- Nhập tên my_database_gui → Apply.
- Kiểm tra câu lệnh do Workbench sinh → Apply → Finish.
- Làm mới SCHEMAS và kiểm tra CSDL đã được tạo.
